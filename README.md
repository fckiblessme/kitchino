# Kitchino

Приложение для сотрудников ресторана: склад с рецептами, партии готовых блюд со сроками годности и автоматическими скидками, учёт сотрудников и защищённый журнал действий.

Учебный командный проект (Android, Kotlin). Тема: какие продукты есть на складе; готовые блюда и срок их годности — при приближении к истечению списание или скидка; фиксация, какой сотрудник приготовил блюдо; рецепты для обучения новых сотрудников.

## Возможности

### Роли и вход
- вход и регистрация по PIN-коду, PIN хранится только в виде хеша;
- три роли: повар, кассир, менеджер;
- права проверяются централизованно (`PermissionChecker`), меню приложения фильтруется по роли.

### Модуль «Склад и рецепты»
- ингредиенты и партии ингредиентов со сроками годности;
- рецепты: состав блюда в ингредиентах и количествах;
- «приготовить блюдо» списывает ингредиенты по рецепту, сообщает, чего не хватает, и создаёт партию готового блюда с указанием сотрудника;
- прогноз «на сколько дней хватит продукта» и признак «пора заказывать».

### Модуль «Партии блюд и скидки»
- каждая приготовленная партия хранит блюдо, количество, время изготовления, срок годности, автора и статус;
- движок решает по партии «ничего / скидка / списание» — цепочка чистых функций:
  1. базовое решение по доле оставшегося срока годности (пороги 5/20/50%);
  2. усиление по темпу продаж: если по текущему темпу партия не успевает продаться до истечения, скидка растёт;
  3. гистерезис: применённая скидка не ослабляется, списание проходит всегда;
- темп продаж считается по журналу продаж за окно наблюдения 12 часов;
- продажи и решения пишутся в БД и в журнал аудита;
- измеримое свойство: симуляция дня ресторана (`DaySimulation`) показывает снижение списаний с 27 000₽ до 12 000₽ (−55%) при том же спросе.

### Модуль «Сотрудники и аудит»
- учётные записи сотрудников с ролями;
- защищённый журнал действий: каждая запись хранит хеш предыдущей (SHA-256), подмена любой записи обнаруживается проверкой цепочки — на экране аудита видно, с какой записи нарушена цепочка;
- раздел обучения: карточки вопросов по рецептам для новых сотрудников.

## Технологии
- Kotlin, Jetpack Compose, Material 3;
- Room — единая локальная база (minSdk 24);
- Coroutines и Flow;
- Gradle с version catalog, JDK 17;
- CI: GitHub Actions — сборка и тесты на каждый push/PR в `main`.

## Сборка и запуск
1. Android Studio (JDK 17).
2. `git clone` → открыть проект → Run `app`.
3. Сборка из консоли:

```bash
./gradlew build      # сборка + проверки
./gradlew test       # unit-тесты
```

Минимальная версия Android — 7.0 (API 24), целевая — 16 (API 36).

## Структура кода
```
app/src/main/java/com/kitchino/app/
├── auth/            вход и регистрация
├── core/contracts/  API-контракты между модулями (WarehouseApi, EmployeeApi, AuditApi, TrainingApi)
├── warehouse/       склад и рецепты
├── dishbatch/       партии блюд и движок скидок
├── employee/        роли, обучение, аудит
├── navigation/      навигация
└── ui/              общие экраны и тема
```

Внутри каждого модуля одинаковые слои: `data/` (Room-сущности и DAO) → `domain/` (чистая логика без Android) → `ui/` (Compose + ViewModel). Модули общаются только через контракты из `core/contracts`.
