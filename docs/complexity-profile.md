# Профиль системной сложности проекта Kitchino

Версия: 1.0. Автор: Стрельцова В.С. Дата: 18.10.2026.

Для зоны ответственности dishbatch рассматриваются два направления системной сложности и модуль-кандидат для дальнейших исследований.

## 1. Хранение и обработка данных

**Объект:** локальная база данных Room, схема v1→v2→v3, журнал продаж `sales_log`.

**Вопросы:** как обеспечивается согласованность схемы при обновлении приложения; что происходит с данными при невозможности миграции.

**Текущее состояние:**
- схема версионируется; миграции 1→2 и 2→3 описаны в `AppDatabase.kt`;
- для учебного проекта добавлен `fallbackToDestructiveMigration()` — при невозможности миграции база пересоздаётся;
- журнал `sales_log` создан в v3 с индексом по `idDish`.

**Готовность:** средняя. Миграции покрыты проверкой на копии базы v1, но автоматического теста миграции нет (не экспортируется каталог `app/schemas`).

## 2. Модель исполнения

**Объект:** асинхронность в `DishBatchViewModel` — корутины, `suspend`, `StateFlow`.

**Вопросы:** как интерфейс получает данные из БД без блокировки главного потока; как устроен поток активных партий.

**Текущее состояние:**
- обращения к БД выполняются `suspend`-функциями из `viewModelScope`;
- `activeBatchesWithDecisions` построен на `Flow.map(...).stateIn(WhileSubscribed)`.

**Готовность:** высокая. Требование NFR-04 соблюдено, `allowMainThreadQueries` не используется.

## 3. Модуль-кандидат

**Модуль-кандидат:** `DiscountDecisionProvider` — принятие решений о скидках и списании.

**Почему пригоден для отдельного исследования:**
- изолирован от UI и БД, вход/выход — простые данные;
- воспроизводимый вход: `DishBatchEntity` + `currentTime`;
- две реализации (`ExpiryDiscountDecision`, `VelocityDiscountDecision`) позволяют сравнивать поведение.

## Направление дальнейшей работы

1. Экспорт схемы Room (`room.schemaLocation`) и тест миграции через `MigrationTestHelper`.
2. Транзакция `@Transaction` для связки «запись продажи + уменьшение остатка партии».
3. Вынос контрактов в `core/contracts` по образцу `WarehouseApi`.
