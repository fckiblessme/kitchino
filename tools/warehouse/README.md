# Модуль обмена между двумя процессами (практическая работа МДК01.04 3)

Назначение: передача списка ингредиентов склада от процесса-источника
процессу-приемнику. Обе стороны написаны студентом (Скрыпникова Д.М.).

## Контракт обмена

| Часть контракта | Решение |
|---|---|
| Направление и стороны | Producer передает, Consumer принимает, обмен односторонний |
| Механизм | сокет TCP на 127.0.0.1, порт 47001 |
| Кадрирование | четыре байта длины в порядке старший байт первым, затем тело в UTF-8 |
| Предельный размер | 256 байт, при превышении кадр отвергается до выделения памяти |
| Закрытие и конец потока | конец потока между кадрами - штатное завершение; обрыв внутри кадра - ошибка |
| Ошибки | недопустимая длина, обрыв посреди кадра, ошибка записи в закрытое соединение |

## Сборка и запуск

    javac -encoding UTF-8 -d out src\ipcdemo\*.java

Терминал 1 (приемник):

    java -cp out ipcdemo.Consumer 47001 read

Терминал 2 (источник):

    java -cp out ipcdemo.Producer 47001 5 close

Режимы источника: close (штатное закрытие), split (кадр передается частями),
hold (конец записи не закрывается). Режимы приемника: read, closeAfterFirst.
